# 積立未来シミュレーター

「毎月いくらで、未来はいくら？」を気軽に試せる、初心者向けの積立シミュレーターです。月末積立・月次複利で簡易試算します。

## 主な機能

- 積立期間から将来の想定資産額を試算
- 目標金額に到達するまでの年月を試算
- 元本と想定運用益のPlotly積み上げ面グラフ
- 500万・1,000万・2,000万円の節目と利回り別比較
- 結果に応じて育つ「未来の木」表示

## 使用技術

Python / Streamlit / Plotly / pandas

## ローカル起動

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

テストは `python -m pytest` で実行できます（pytestは開発環境に別途導入してください）。

## 公開

Streamlit Community Cloudでこのリポジトリを接続し、エントリーポイントに `app.py` を指定すると公開できます。画像は既存の `assets/` を参照するため、同じ構成でデプロイしてください。

> 本アプリは想定利回りに基づく簡易試算であり、実際の運用成果を保証するものではありません。
